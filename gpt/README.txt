# RUANG HIJAU — Website Tanaman

Project Pemrograman Web 1
Teknologi: HTML, CSS, JavaScript murni.

## Fitur
- Multi-page website
- Katalog tanaman
- Pencarian dan filter kategori
- Filosofi setiap tanaman
- Keranjang belanja sederhana
- localStorage untuk menyimpan keranjang di browser
- Form kontak dengan validasi HTML + JavaScript
- Responsive untuk desktop dan mobile

## Struktur
- index.html
- koleksi.html
- filosofi.html
- tentang.html
- kontak.html
- css/style.css
- js/script.js

## Cara menjalankan
Buka `index.html` menggunakan browser.

Tidak membutuhkan Node.js, database, framework, atau backend.
